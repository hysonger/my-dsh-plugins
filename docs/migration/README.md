## 历史处理

所有处理先在副本中完成。使用 Git 自带的 `fast-export --full-tree` / `fast-import`，仅给文件路径增加对应插件目录前缀。转换程序按 Git 的 `data <字节数>` 读取完整数据块，避免将二进制文件或提交说明误当成命令处理。

对每个导入提交逐一验证：

- 文件路径只增加目录前缀，文件模式、类型和 blob ID 保持一致。
- 作者、提交者、时间、编码及提交说明保持一致。
- 父提交按映射保持原来的顺序和关系。

路径改变使提交 SHA 改变。[commit-map.tsv](commit-map.tsv) 保存旧 SHA 与新 SHA 的对应关系，其中 `original` 是原有提交，`snapshot` 是迁移时保存的未提交开发成果。各插件历史通过独立合并提交接入 `main`，没有压缩或线性化原历史。

## 回滚材料

切换前保存了五个插件的完整目录，包括 `.git`、未提交文件和现有依赖，另保存原根目录 `AGENTS.md`、原仓库 bundles、文件哈希及权限清单。切换时将原来的五个 `.git` 移入同一备份目录。

只有历史、文件、测试和本地安装配置全部核对通过后，才将整个迁移备份目录移入 macOS 废纸篓，保留恢复能力。废纸篓目录中的 `README-ROLLBACK.txt` 说明恢复方法。
